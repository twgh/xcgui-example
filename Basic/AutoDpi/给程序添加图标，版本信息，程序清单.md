# 给程序添加图标，版本信息，程序清单

## 一、获取所需工具

```Bash
go install github.com/twgh/xc@latest
```

执行完毕后 **GOPATH** 的 **bin** 目录里出现一个 **xc\.exe** 则为成功。

## 二、在 main 函数所在目录中执行命令

```Bash
xc res init
```

执行成功后，该目录下会出现一个 **winres** 目录

## 三、打开 winres 目录

1. 修改 **winres\.json** 中 **RT\_VERSION** 字段下的版本信息

2. 将 **icon\.ico** 文件放入 winres 目录中，ico 中最好包含 16，24，32，48，64，256 尺寸的图片以达到最好显示效果

## 四、生成 syso 文件

在 winres 父目录（也就是 main 函数所在目录）中执行命令，成功则目录中出现 syso 文件

```Bash
xc res make
```

## 五、最后编译程序即可看到效果
