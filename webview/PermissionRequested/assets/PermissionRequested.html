WebView2 权限请求演示(Event_PermissionRequested)

点击下面的按钮, 页面会调用 navigator.geolocation.getCurrentPosition 请求地理位置权限, Go 侧的 Event_PermissionRequested 事件会弹出消息框询问你允许还是拒绝, 授权结果会显示在下方.

这里显示授权结果.

说明: 本页面通过虚拟主机名 https://permission.example/ 加载, 来源是安全上下文, 所以地理位置 API 可用(NavigateToString 加载的 about:blank 页面则会被直接拒绝). 拿到具体位置还需要 Windows 系统开启定位服务; 若系统定位不可用, 页面会显示相应错误, 但 Go 侧的权限请求(允许/拒绝)流程是一样的.
